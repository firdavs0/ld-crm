# L&D CRM — отдельный сайт

Автономная версия CRM (без привязки к Claude), с общим хранилищем данных
на Supabase. Разверни один раз на Vercel — получишь постоянную ссылку
для всей команды.

Подробная пошаговая инструкция — в ответе чата, где ты это получил.
Коротко:

1. Создай проект на supabase.com, выполни `supabase-setup.sql` в SQL Editor.
2. Скопируй `.env.example` в `.env` и впиши URL и anon key проекта.
3. `npm install`
4. `npm run dev` — проверить локально.
5. Залей папку на GitHub, импортируй репозиторий в Vercel, добавь те же
   переменные окружения в настройках проекта Vercel, нажми Deploy.
